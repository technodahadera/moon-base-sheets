# משימת בסיס ירח 🌙 – גרסת Google Sheets

משחק כיתה חי לטבלטים: כל ילד מתכנן בסיס קבע על הירח בשבעה שלבים, והמורה רואה את ההתקדמות על לוח חי.

- מסך המורה (להקרנה): https://technodahadera.github.io/moon-base-sheets/teacher.html
- מסך התלמידים (או סריקת ה-QR מהלוח): https://technodahadera.github.io/moon-base-sheets/

## איפה הנתונים נשמרים
כל הנתונים נשמרים בגיליון Google של המורה, **"משימת בסיס ירח"**, דרך Apps Script שמחובר אליו. אין שרת נוסף. ב-GitHub יש רק את דפי המשחק.

לשוניות בגיליון:
- **חדרים** – קוד חדר, מצב, מתי נפתח/התחיל/הסתיים, מספר תלמידים
- **תלמידים** – שורה לכל תלמיד: שלב, ניקוד, אתר נחיתה, מקור חשמל, זמן
- **תשובות** – שורה לכל תשובה: זמן, קוד חדר, שם, שלב, שאלה, בחירה, נכון?, נקודות

עמודות "(טכני)" משמשות את המשחק: אפשר להסתיר, לא למחוק ולא להזיז.

## קבצים
- `index.html`, `student.js` – מסך התלמיד (`?code=1234`)
- `teacher.html`, `teacher.js` – מסך המורה: קוד, QR, לובי, התקדמות חיה, פודיום וסיכום כיתתי
- `config.js` – כתובת ה-/exec של Apps Script (`SHEETS_URL`)
- `api.js` – החיבור ל-Apps Script
- `Code.gs` – עותק של הסקריפט שבגיליון (לעיון; הקוד שרץ באמת הוא זה שבגיליון)
